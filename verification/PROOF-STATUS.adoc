Creusot verifies Rust implementations; Pearlite expresses their contracts.
Verus supplies complementary specifications and proofs. It does not execute
Pearlite contracts, and an independent model is not a second proof of the
production implementation.

== Toolchain provisioning deviations

`CREUSOT-INSTALL` is open: the reusable Creusot workflow currently installs
Creusot 0.14.0 from its upstream release tag with Rust nightly-2026-08-03,
outside the repository's Guix/container environment. The workflow is pinned to
`proven-cicd-and-workflows@9eb0bbf9bd80b7964ce5b9957e75821b3cd4a55b`.
A qualified Guix/container proof-toolchain build and an immutable upstream
installation digest are still required; the suite pin alone is not that digest.

`VERUS-INSTALL` is open: the native Verus workflow downloads release
`0.2026.11.02.8bf68ee`, archive SHA-256
`f3a0119292df8855e4435da8130bee1873b0e6a60c306accf81a08ea687bba3c`,
with Rust 1.99.1. This enables the model check while the Guix/container proof
toolchain remains unqualified. Close the deviation only after that environment
has a successful recorded build and replay.

Any source, contract, dependency, verifier, solver, target-width or proof-gate
change triggers revalidation of the affected rows. Record exact versions,
source identity, invocation, positive/negative controls and discharged scope
with each new receipt; a setup failure is not a proof result.
