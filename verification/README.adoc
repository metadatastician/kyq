= Verification boundary

link:PROOF-STATUS.adoc[The proof-status ledger] assigns Creusot/Pearlite and
Verus scopes, implementation connections, assumptions and outstanding work.

`bounds` is the runtime resource-accounting kernel. Its Pearlite postcondition
states that a successful consumption is the mathematical sum and stays within
the limit, and refusal means that sum exceeds the limit. Creusot 0.14.0 checks
these obligations; Rust tests alone do not discharge them.

`verus/budget.rs` is an independent model of the same operation. A successful
Verus run proves that model. It does not prove the YAML scanner, Dhall evaluator,
JCS implementation or a refinement relationship between independent programs.

Commands:

[source,sh]
----
cd verification/bounds
cargo creusot
# From the repository root:
verus --no-cheating --crate-type lib verification/verus/budget.rs
----
