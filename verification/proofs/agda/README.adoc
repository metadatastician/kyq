== What the spine models

* `V_J`, the I-JSON value algebra (`KyqValue`): null, bool, number, string
  (UTF-16 code units, each a `ℕ`), array, and object as an association list in
  the order the producer wrote it. Numbers are an abstract module parameter
  `Num`.
* `canon`, the value-level canoniser: object members sorted by name in UTF-16
  code-unit order (RFC 8785 §3.2.3), recursively.
* An abstract codec (`KyqCodec.Format`): texts, a partial parser
  `p : Bytes → Maybe V` (refusal is `nothing`, fail-closed), a printer, the
  value canoniser `norm`, and a profile domain `Dom`. Nothing about `p` or
  `print` is built in: each law is a separate named hypothesis, and each
  theorem lists the ones it uses.
* The I-JSON number profile (`KyqProfile`) over an abstract number interface
  `NumIface` whose only hypothesis, `show-val`, is a record field. Its
  `Bytes` are token trees (value trees with numerals at the leaves), not
  bytes.

It does *not* model bytes, UTF-8 encoding, escaping, number text, headers or
trivia, KYAML, TOML, Dhall, the JS conformance oracle or the AffineScript
code. See `docs/status/PROOF-STATUS.adoc`, "What is NOT proven".

=== The translation-validation theorem (verify-logic L1)

`tv-sound`: for any `check` with `NonMalleable check`, any input `i` with
`p i ≡ just vi` and `Dom vi`, and any output `o` with `check o ≡ true` and
`p o ≡ just vo`, `vo ≈ vi`, it follows that `o ≡ c vi`.

Assumed about `p`/`print`: *nothing* beyond `NonMalleable check` and the
definition `c v = print (norm v)` (so `c` respects `≈`). `tv-complete` adds
`RoundTrip`, `Complete check` and idempotence of `norm`. `tv-iff` combines
them: `TV check i o ⇔ ∃ vi. p i ≡ just vi ∧ Dom vi ∧ o ≡ c vi`.

`one-arg-not-tv` shows why the one-argument form `check b ⇔ b = c(p b)` is
not translation validation. `validity-not-tv-sound` shows that `tv-sound`
needs `NonMalleable`: with a validity gate in its place the statement is
false.

The hypotheses are satisfiable in two witnesses. `KyqModel.model` is
degenerate (total parser, `Dom = ⊤`). `KyqProfile.toy-gate` has a partial
parser and a proper domain: there `toy-tv-refused` (the parser refuses the
input) and `toy-tv-outside-dom` (the input parses, but its value is the
large-float hole) show that the refusal and `Dom` parts of TV bite.

=== Closure: what is derived and what is assumed (ruling R3)

* `closure : NormIdem → RoundTrip → DomClosed → ∀ v → Dom v → Canonical (c v)`
  gives the *accept-set half* of JCS-10: `c v` lies in the set a canonical
  gate must accept. It says nothing about a given `check`.
* `check (c v) ≡ true` for a given `check` is `Complete check`. In `tv-complete`
  and `tv-iff` it is a hypothesis.
* For the *reference check* `RefCheck.checkRef` (parse, decide `Dom`, compare
  with `c`), `gate-closure` derives `CanonicalGate checkRef`, so
  `check (c v) ≡ true` is proved from `NormIdem`, `RoundTrip` and `DomClosed`.
  `Gate.profile-gate-closure` instantiates it for the I-JSON number profile
  under R3, for any `NumIface` with decidable numeral equality.
* For kyq's *actual* `check`, gate-level closure is `open`.

=== Faithful≈, ≈ and declared losses (verify-logic L2)

* `≈` is the kernel of `norm`. A `Crossing` takes no `≈` parameter, so a
  converter cannot pick one. But `norm` is a field of the `Format`, so `≈` is
  only as good as the `Format` instance: `coarse-norm-faithful` builds a
  `Format` with a constant `norm` that meets `CanonicalGate`, `RoundTrip` and
  `NormIdem`, and with it a converter that drops the whole document is
  `Faithful≈`. `free-≈-trivial` has moved into the choice of `Format`.
* The fix is `NormSeparates sem`: `norm` identifies only what an
  independently defined equivalence `sem` identifies. For JSON, `sem` is
  `KyqRecursive._~_`, and `model-separates` proves it (via `ker-sound`);
  `coarse-not-separating` refutes it for the constant `norm`. `FaithfulSem`
  adds it to `Faithful≈`, and `sem-roundtrip` concludes the round trip up to
  `sem`.
* Every `Faithful≈` claim is therefore only as good as an audited, exported
  `Format` instance and its `sem`. That is a trust-boundary row in
  PROOF-STATUS.
* `Covered≈ img` is relative to an image predicate `img`, not to the target's
  `check`. It is vacuous at `img = ⊥` (`covered-vacuous`) and trivial at the
  image of `fwd`; `wrap-not-covered` shows it failing for an embedding into a
  larger target at `img = ⊤`. A crossing fixes `img` per output as its "no
  invented field" predicate; that choice is audited with the instances.
* `NonMalleable check` is its own component; `covered-not-enough` exhibits a
  crossing with `RoundTrip≈` and `Covered≈` but a malleable check.
* Declared losses are a separate quotient `_≋_ ⊇ ≈_S`. They set the grade
  (`GradeEvidence`), never `≈`.
* FID-1: `faithful-compose` composes `Faithful≈` under `Chain`, `BackCong`,
  `FwdCong` and `ImgChain`. Composition of grades (by max) is not proved.

=== Canonical gates and validity gates (verify-logic L3, CORRECTIONS blocker 5)

[cols="1,1,2",options="header"]
|===
| Kind | Formats | Obligation in `KyqCodec`

| Canonical gate | KYAML, I-JSON/JCS | `CanonicalGate check = NonMalleable check × Complete check`, plus `RoundTrip` (which gives `closure`, the accept-set half).
| Validity gate | TOML, Dhall | `ValidityGate check = ∀ b. check b ≡ true ⇔ b ∈ Dom` only, plus `RoundTrip` for any emitter. No non-malleability.
|===

`canonical-gate-valid` shows a canonical gate is also sound as a validity
gate; `loose-validity` with `loose-not-nonmalleable` shows the converse fails.
No TOML or Dhall instance is built here.

*Open definitional gap: headers and trivia.* `NonMalleable` requires
`b ≡ c v` exactly. verify-logic L3 asks for `b = h ++ c v` with a preserved
header `h`. Without that component, any KYAML instance would have to refuse
every file that starts with an SPDX line, which is the root of CORRECTIONS
blocker 2 and doctrine 6. The header form needs a byte model with
concatenation, which P1 does not have; it is recorded as `open` in
PROOF-STATUS and blocks any KYAML instance.

=== The large-float hole (verify-logic L7, ruling R3)

The hole is a failure of `RoundTrip` of the *profile* reader `readP`, which
classifies a numeral as integer form or not and refuses integer-form numerals
outside the safe range. It is not a hypothesis on `Num`: `NumIface` keeps only
`show-val`. `hole-breaks-rt` refutes RoundTrip on the pre-R3 domain whenever
a hole exists; `toy-hole` exhibits one in a concrete interface (`expTok 4` plays
`1e18`); `r3-rt` proves RoundTrip on the R3 domain; `r3-maximal` shows R3
refuses nothing that closure does not force it to refuse; `domR3B-sound` and
`domR3B-complete` show the R3 domain is decidable.

=== Value budgets (ruling R3)

`canon-measure` holds for every `Measure`, that is, every fold whose member
combination is left-commutative. `depth`, `nodes` and `bytes` are its
instances, defined as `conformance/src/budgets.js` defines them: depth counts
containers only (`[]` is 1, `[[1]]` is 2, a scalar adds nothing), so a budget
of 127 matches the ijson-jcs text limit and the oracle's `MAX_DEPTH`; nodes
exclude keys; bytes are UTF-8 bytes of strings and member names (a valid
surrogate pair is 4 bytes, a lone surrogate 3). `verdict-canon` shows the
typed verdict (which budget is exceeded first) is the same for `v` and
`canon v`. The two alias-expansion budgets and the encoded-bytes CLI limit are
not modelled.

== Invocation and import cone

----
LC_ALL=C.UTF-8 agda --safe --without-K --cubical-compatible --no-libraries All.agda
----

`LC_ALL=C.UTF-8` is needed because Agda 2.6.3 aborts on the UTF-8 source
without a UTF-8 locale. `--no-libraries` keeps a user's `~/.agda/defaults`
out of the include path. `verification/proofs/run-proofs.sh agda` (or
`just proofs-agda`) runs it from a clean state and also checks:

* coverage: every `./*.agda` is imported by `All.agda`, and the cone Agda
  reports with `--dependency-graph` is exactly `All`, the local modules and the
  prover-supplied modules, so a stray module cannot go unchecked;
* escape hatches, with a lexing scan (`../agda-lex.awk`) that strips nested
  comments, strings and character literals and reads pragma bodies as Agda
  does: no `postulate`, `primitive`, `primTrustMe` or `primEraseEquality`, and
  no pragma outside an exact allowlist;
* the prover's trusted base (PROOF-POLICY §8.4 rule 7): the postulates of the
  prover-supplied modules in the cone are exactly `Level`, `lzero`, `lsuc` and
  `_⊔_`, bound by `BUILTIN LEVEL`, `LEVELZERO`, `LEVELSUC` and `LEVELMAX`;
* each scanner and coverage check is first run, with the same function, on a
  planted control under `controls/runner/`, and must flag it.

Import cone (from `--dependency-graph`): `All`, `KyqPrelude`, `KyqOrder`,
`KyqValue`, `KyqUnique`, `KyqRecursive`, `KyqMeasure`, `KyqCodec`,
`KyqModel`, `KyqProfile`, and the prover-supplied `Agda.Primitive`. No
standard library or other library is imported. Pragmas: the canonical
`OPTIONS` line and `BUILTIN EQUALITY _≡_`/`BUILTIN NATURAL ℕ`. Development
postulates: 0. Prover trusted base: 4 named postulates of `Agda.Primitive`,
listed above.

== Negative controls

Each file under `controls/` must be refused, with the stated reason; the
runner fails if one is accepted or refused for another reason. A refusal
shows that the checker rejects that proof of that claim; where the claim is
also false, the spine proves its negation, named in the table.

[cols="2,3,2",options="header"]
|===
| Control | Claims (and the theorem that refutes it) | Expected refusal

| `PlantedPostulate.agda` | `true ≡ false` by postulate | `Cannot postulate cheat with safe flag`
| `PlantedTerminating.agda` | a non-terminating loop under `TERMINATING` | `Cannot use TERMINATING pragma with safe flag`
| `KInForce.agda` | uniqueness of identity proofs | `... because K has been disabled`
| `UnsortedIsNF.agda` | one unsorted object is a normal form (`unsorted-moved`) | `false != true of type Bool`
| `MalleableCheck.agda` | F-2: `NonMalleable checkLoose`, a validity gate is non-malleable (`loose-not-nonmalleable`) | `b != canon b of type Value`
| `IsortUniqueNoDistinct.agda` | ablation: `isort-unique` without `DistinctKeys` (`no-unique-without-distinct`) | `⊤ !=< (DistinctKeys xs)`
| `CanonRespNoWF.agda` | ablation: `canon-resp` without `WF` (`canon-resp-needs-wf`) | `⊤ !=< (WF v)`
| `TvSoundValidity.agda` | ablation: the `tv-sound` proof term with `ValidityGate` for `NonMalleable` (`validity-not-tv-sound`) | `(InDom o → check o ≡ true) should be a` function type
| `LargeFloatClosed.agda` | the pre-R3 toy profile reads back the printed `4` (`toy-old-not-closed`) | `nothing != just 4`
|===

Runner controls under `controls/runner/` are not Agda controls: they test the
runner. `KyqStray.agda` (an unimported, false module) must be flagged by both
coverage checks; `LexHidden.agda` (a postulate after a nested comment on the
same line) must be found by the lexing scan; `LexDecoys.agda` (the word
`postulate` only in comments, a nested comment, a string and inside a name)
must not be.

[cols="1,1,3",options="header"]
|===
| Agda | Rocq | Differences found by reading

| `leq-total`, `leq-antisym`, `leq-trans` | `leq_total`, `leq_antisym`, `leq_trans` | Agda's `leq` goes through `cmpN`/`leqStep`; Rocq's through `Nat.ltb`/`Nat.eqb`. Same function by reading; not proved equal.
| `canon-nf`, `nf-fixed`, `canon-idem` | `canon_nf`, `nf_fixed`, `canon_idem` | Agda `NF` is a recursive predicate; Rocq `NF` an inductive predicate over `Forall`. Rocq objects are `list (key * value)` sorted with `isort ∘ map canonM`, Agda's `isort ∘ canonO`.
