== How to use

* One row per boundary file (application code, frontend, middleware,
  configuration, persistence, generated artifacts, benchmarks, scripts, tests,
  workflows, hooks, installers).
* Classification: first-party | legacy/versioned | third-party | generated | invalid test fixture | independent reference oracle.
* Do not count every `JSON3`/`JSON.stringify`/`YAML` occurrence as a violation;
  classify first (handover step 5).
