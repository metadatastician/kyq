== A2 control details

`scripts/affine-a2-controls.sh` is fail-closed for control violations and uses
the same pinned compiler and stdlib as the census:

. `imported_positive`: a consumer calling an imported `Int -> Int` dependency
  passes.
. `imported_type_error`: the identical module layout, with only the dependency
  body changed to a string, exits 124 with
  `ImportError("Type checking failed: ... TypeMismatch (Int, String)")`.
  v0.1.1 omits the dependency filename from this wrapped diagnostic; the
  positive/negative twin is the coverage control. The script does not invent a
  filename assertion.
. `dict_association_list`: a consumer typed as `[(String, Int)]` checks calls
  to the released `dict::{empty,set,contains,get}` functions. This demonstrates
  the existing representation and typed API, not runtime map behaviour.

The first control-diagnostic run (40232709967) exposed the wrapped-error shape;
the assertion was corrected to the evidence rather than bypassing the negative
control. The final run above is the accepted result.

== Source-port decisions

* All implementation remains AffineScript. No JavaScript/Python replacement was
  added.
* Function expressions use explicit imports and unqualified calls; v0.1.1's
  `Type::Variant` expression production does not make `Module::function` valid.
* Association lists and the released `dict` API are sufficient; no Map request
  is needed.
* Structured loops/matches and `char_to_int` replace unsupported or
  type-rejected constructs locally.
* Imported struct declarations still do not populate v0.1.1's importer
  `type_env`. Scoped structural aliases preserve exact field layouts in Parser,
  Kyaml, and RequiredFields. The upstream fix/removal path is in
  `docs/UPSTREAM_HANDOFFS.adoc`.
* A6's explicit key comparison is a source port, not proof of UTF-16 ordering
  across every runtime. The pinned I-JSON/JCS large-float interaction remains a
  later contract task.

== What remains open

. **A7 CLI:** no released, digest-pinnable toolchain has yet demonstrated the
  required multi-module WASI CLI contract for argv, complete stdin, stdout,
  stderr, and exit statuses. `Main.affine` still prints usage text only.
. **Execution:** the 19 parser fixtures and one lint fixture have been checked,
  not run. No `affinescript eval`, Deno-ESM, or WASM execution PASS is claimed.
  Source inspection shows that eval does not flatten imports and Deno's
  flattener is not a proven transitive type/helper linker; an actual released
  multi-module execution fixture is required before choosing a test path.
. **A8:** full build, test execution, WASM smoke tests, and their inverse
  controls remain open. The JavaScript conformance gate is only an oracle.
. **Semantics:** the lexer and required-fields rule are stubs; the parser is
  minimal and still has known contract gaps (including duplicate-key panic and
  rejected document streams). JCS/I-JSON validation is incomplete.
. **Governance:** the standards owner repair allows called workflows to run,
  but the pinned upstream allowlist still needs its narrow
  `metadatastician/standards@*` correction. See PR #18 and the first handoff
  prompt.
. **Dependencies:** PyYAML is not removed by this source-check milestone, and
  no kyq release artifact or CLI is claimed.
