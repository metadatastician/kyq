== Blockers

. **AffineScript 0.1.1 does not parse the sources.** Measured 2026-10-07:
  `affinescript check` reports `parse error: Syntax error` at line 7 or 8 of
  every one of the 9 tracked `.affine` files (6 under `src/`, 2 under
  `tests/`, 1 under `benches/`). Until that changes,
  `just build`, `just wasm`, `just test` and `just bench` fail with
  "not implemented" rather than emit a placeholder.
+
*Update 2026-10-23:* Phase 0 mechanical port done on `arena/dc1301aa-kyq`:
`src/Kyaml/Ast.affine`, `src/Main.affine`, `src/Kyaml.affine`,
`src/Kyaml/Lexer.affine`, `src/Kyaml/Parser.affine`,
`src/Kyaml/Lint/RequiredFields.affine`, `src/Kyaml/Jcs.affine`,
`src/Kyaml/Ijson.affine`, `tests/*.affine`, `benches/*.affine` now use
0.2 grammar (`module X;`, `use` not `import`, `dict` assoc-list
`[(String, V)]` not `{}String -> V`, variant renames `YamlString` etc.,
`Option[String]` from `prelude`). Full control-flow rewrites still
TODO; see `docs/AFFINESCRIPT_STRICT_PORT.adoc` A1-A8. Verify with
`just affine-check` when toolchain is present.
+
*Update 2026-10-24 (A1 census):* the minimal empty/module/function slice
passes the digest-pinned v0.1.1 asset. With its pinned stdlib and checks run
from `src/`, 3 of 11 tracked files pass `check` (`Ast`, `Ijson`, `Lexer`), 6
have direct parse failures, and 2 entry points fail through those imports.
This supersedes “none of them compiles” as the current state, not as a report
of the original measurement. It is not a full build/test/WASM/CLI PASS. Exact
probes and diagnostics: `docs/status/A1_GRAMMAR_CENSUS.adoc`, CI run 40090907337.
. **The gap is a port, not a fix.** Read against the v0.1.1 grammar
  (`lib/parser.mly`), not yet confirmed by the compiler past line 7: about
  half of the 2456 lines need touching. Roughly 5% is mechanical (`module X;`
  needs its semicolon, `import` becomes `use`, no trailing enum commas,
  `&mut T` becomes `mut T`). The remaining semi-mechanical delta confirmed by
  A1 is no variant named after a builtin type such as `String` or `Int`;
  record literals and multi-segment paths passed their probes. The rest is a
  rewrite: legacy map types, `break`/`continue` and working `if let` binding
  are rejected. The AST now uses association lists and passes `check`, while
  parser/query control flow still needs structured equivalents.
. **No program input in the WebAssembly target.** The 0.1.1 toolchain gives
  a compiled module no access to argv or stdin, so even a parsing build
  could not read a manifest from the command line.
+
*Update 2026-10-23:* affinescript `main` now documents WASI preview1
`file_open`/`file_read`/`file_fd_write` and preview2 import lowering;
`just build` will target that once A3 (block → file I/O) lands.
. AffineScript text-processing libraries have not been verified for YAML
  parsing.
. Performance benchmarks against yq have not been established.

=== Tactics

* **Incremental rollout:** run kyq alongside yq, compare results, replace
  gradually.
* **Performance optimization:** profile and optimise parsing speed and memory.
* **Community adoption:** promote adoption across the hyperpolymath and
  metadatastician estates.

== Next actions

  through A2–A6; re-run all 11 tracked `.affine` files against each pinned
