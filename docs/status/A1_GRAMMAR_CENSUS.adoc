== Outcome

*A1's minimal slice clears.* The zero-byte file, `module A1;`, and a minimal
typed function all have `parse` and `check` exit code 0. The full port does not
clear: the current ratchet is **3 passing / 8 failing across 11 tracked
`.affine` files**. The three passing files are `src/Kyaml/Ast.affine`,
`src/Kyaml/Ijson.affine`, and `src/Kyaml/Lexer.affine`.

No `MISSING_TOOLCHAIN` occurred in the authoritative run. A local negative
control without `affinescript` on `PATH` exited 2 and printed
`MISSING_TOOLCHAIN`, as required. The local gate now also rejects a missing
stdlib instead of silently skipping or misreporting import failures.

== Reproduce

[source,bash]
----
export AFFINESCRIPT=/path/to/affinescript-linux-x64
export AFFINESCRIPT_STDLIB=/path/to/affinescript-26cdb43/stdlib

# Non-gating one-construct + full-source census.
bash scripts/affine-a1-probe.sh

# Gating check: rc=2 for missing compiler/stdlib; rc=1 while any source fails.
just affine-check
----

Project checks run from `src/`. This is required by the v0.1.1 module loader:
it searches the current directory and `AFFINESCRIPT_STDLIB`, not `src/`
implicitly. Tests and benches are checked as `../tests/...` and
`../benches/...` from that directory.

== A2–A4 checklist derived from the probes

. Keep the already-ported `module ...;`, `use`, multi-segment paths, `#{...}`,
  `Option[...]`, and association-list types. Multi-segment paths are not a
  v0.1.1 blocker.
. Keep `prelude` imports where `Some`/`None` constructors are used and always
  provide the pinned stdlib. A missing stdlib is `MISSING_TOOLCHAIN`, not a
  source regression.
. Do not reintroduce `{}String -> V`, trailing enum commas, variants named
  `String` or `Int`, or `&mut` parameters.
. Rewrite every `break` and `continue`; token existence is not grammar support.
  The first parser failure is now `src/Kyaml/Parser.affine:23:12`, at `break`.
. Rewrite `if let` as `match`. Its surface tokens can parse as a generic `if`
  with a let expression, but the expected branch binding does not resolve.
. Work the direct parse failures before treating entry-point `ImportError`s as
  separate work: `Kyaml.affine`, `Parser.affine`,
  `Lint/RequiredFields.affine`, `Jcs.affine`, and the two test files.
. Keep A7/A8 open. This census does not demonstrate WASM argv/stdin, a CLI,
  execution of the test modules, or removal of any existing YAML tooling.
