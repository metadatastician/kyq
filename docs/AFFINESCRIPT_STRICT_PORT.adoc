This note details the work implied by the owner's ruling *strict AffineScript
only* (2026-10-23). No Rust/Cargo code is added; `coordination.k9`
`affinescript-only` stays enforced. The plan turns the ROADMAP Blocker 1
breakdown into actionable upstream and in-repo tasks.

toc::[]

== Why this plan exists

`docs/status/ROADMAP.adoc` Blockers records the original 2026-10-07 result:
AffineScript 0.1.1 did not parse any of the then-9 tracked `.affine` files.
The 2026-10-24 A1 rerun established the minimal slice and a 3-passing/8-failing
baseline. The 2026-10-25 A2–A7 source ports now pass **11 / 11 tracked files**,
with three fail-closed A2 controls. This is still not a full build, test-run,
WASM, conformance, or CLI PASS. `just build`/`test`/`wasm` must not fabricate
artefacts (`no-fabricated-artefacts`). A Rust bootstrap would clear the blocker
sooner, but the owner explicitly rejected it — so we fix the AffineScript side.
See `docs/status/A1_GRAMMAR_CENSUS.adoc` for the baseline and
`docs/status/SOURCE_CHECK_CLOSEOUT.adoc` for every later gate run.

== What the compiler gap is (from ROADMAP)

Roughly 5% mechanical, 25% semi-mechanical, rest rewrite:

* Mechanical: `module X;` needs its semicolon, `import` → `use`, no trailing enum
  commas, `&mut T` → `mut T`.
* Semi-mechanical: no variant named after a builtin type (`String`, `Int`).
  A1 disproved the earlier “two-segment paths only” claim: multi-segment paths
  and `#{…}` record literals both passed their probes.
* Rewrite: the probes reject legacy map-type syntax, `break`/`continue`, and
  working `if let` binding. The sources now use association lists and
  structured equivalents and pass `check`; runtime semantics remain a separate
  gate. Generic `if let` tokens can parse as an `if` containing a let expression, so
  a parse-only result is not evidence of pattern-binding support.

== Upstream tasks (affinescript side)

Ready-to-paste, evidence-scoped handoffs for the current standards, compiler,
WASI-release, and later I-JSON/JCS blockers are in
`docs/UPSTREAM_HANDOFFS.adoc`.

A1 did not file upstream issues. Do not file the disproved path/record/use
claims as grammar gaps. Remaining candidates, each with a minimal reproducer,
are:

* Imported struct definitions must survive module imports in `type_env`; A3
  confirmed this defect and used scoped structural aliases until it is fixed.
* Variant names that collide with builtin types, if upstream wants to support
  them; the in-repo `YamlString`/`YamlInt` spellings already avoid the issue.
* No `Map<K,V>` request is needed for the port: v0.1.1 `stdlib/dict.affine`
  already provides association-list `contains`/`get`/`set` operations.
* Control flow: `break`/`continue` or structured loop alternative, `if let`
  (or `match` desugaring). A3's structured equivalents are sufficient locally.
* WASM I/O: argv/stdin/stdout/stderr imports for the WASM target (blocker 3),
  demonstrated through a multi-module consumer rather than a root-only fixture.
* `affinescript check` import coverage is now controlled by A2's planted
  positive/negative modules; keep that control when repinning.

== How KYAML guarantee is shown before proofs

* Executable spec: `docs/KYAML_SPEC.adoc` + `examples/deployment.yaml` (good) +
  `tests/fixtures/invalid-deployment.yaml` (bad) are the first conformance
  tests.
* Property harness (AffineScript test module, not Rust proptest yet): parse
  totality/determinism, `fmt` idempotence, `get`/`set` round-trip, selector
  soundness — each as an AffineScript test that runs only after A7 establishes
  the real execution path. Checking the source is not running the property.
* Shared corpus with `ijson-jcs`: valid/invalid/canonical JSON triples; `kyq
  canon` (AffineScript) and `ijson-jcs canon` (Rust oracle) must be byte-equal
  (Thm JCS-8). The oracle is external — no Rust code is added to kyq.

== Ordering

Execute the gates in A1 → A2 → A3 → A4 → A5 → A6 → A7 → A8 order; later
semantic work does not retroactively turn an earlier source-check minimum into
a runtime PASS. Phase 1 gate (KYAML working) is A1..A5 plus real build/test
green. Phase 2 gate (JCS canonical) is A6 plus corpus byte-equality. Proofs
(Phase 3) are after both.
