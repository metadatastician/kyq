= Acceptance record — native integration candidate
:revdate: 2026-11-16

== Implemented surfaces

Native Rust KYAML parsing, strict JSON ingress and explicit binary64 JCS delegation, import-free typed Dhall,
JSON Pointer queries, deterministic block formatting, a standalone CLI and
the DocMatrix structured-data API. The production node-budget operation uses
verification/bounds, whose Pearlite contract is checked separately from Rust tests.

== Reproduction

[source,sh]
----
cargo test --locked --all-targets
cargo test --locked --doc
cargo clippy --locked --all-targets -- -D warnings
cargo fmt --all --check
cargo doc --locked --no-deps
----

Native tests cover the 118 bridge vectors and 49 fixture diagnostic contracts,
malformed input, duplicate keys,
safe integer boundaries, alias expansion, cross-document aliases, disabled
Dhall imports, confined Dhall evaluation (a costly input ends with
`DHALL_TIME_LIMIT`, `DHALL_MEMORY_LIMIT` or `DHALL_STACK_LIMIT` inside the
limits in link:CAPABILITIES.adoc[CAPABILITIES]), JSON/JCS agreement, formatter
repeatability and numeric type preservation. The benchmark consumes a real Kubernetes fixture and reports
iterations, input bytes and elapsed time; debug timings are not release targets.

== Recorded executions

At revision `9df66eb`, the 2026-11-16 Debian and Windows native suites passed, including the corpus,
Clippy and formatting. The source-hash-bound Creusot/Pearlite production-budget
proof and complementary Verus arithmetic model both passed with positive and
negative controls; see link:../verification/REPLAY-2026-11-16.adoc[the proof record].
This does not discharge the parser-level obligations in the proof-scope ledger.

W8 part 1, TESTED at base `758825a` with rustc 1.99.1 and yq v4.53.3:

* Estate corpus (`tests/estate_kyaml_corpus.rs`): 260 real YAML files of
  metadatastician/standards at `745fc74`, rendered as KYAML by the pinned yq.
  kyq reads 259 to yq's value; 1 is a listed refusal (`DUPLICATE_KEY`, which yq
  drops silently). Two planted parser faults are found.
* KEP-5295 generator (`tests/kep5295_generator.rs`): 2,000,000 generated
  documents (depth 5, 64 nodes), read back to the value written, or refused with
  a listed code, in 133 s. A planted string-trimming fault is found. CI runs
  1024 cases; set `KYQ_KEP5295_CASES` for a longer run.

W8 part 2, TESTED on base `3abf616` with nightly-2026-11-01, cargo-fuzz 0.13.1
and libfuzzer-sys 0.4.10, 2 workers per target, inputs up to 64 KiB:

* `fuzz/fuzz_targets/kyaml_roundtrip.rs`: 4,118,212 inputs in 3,600 s, no
  crash, timeout or OOM, 7,992 coverage edges. kyq never panics; a stream it
  reads, formatted or written as `canonical_file`, reads back to the same
  per-document RFC 8785 text and is a fixed point.
* `fuzz/fuzz_targets/json_jcs_roundtrip.rs`: 18,093,607 inputs in 3,631 s,
  no crash, timeout or OOM, 2,292 coverage edges. JSON and JCS output is a
  fixed point of read and canonicalize.
* Planted fault: built with `--cfg kyq_fuzz_plant`, the KYAML target drops the
  last element of each re-read sequence. From an empty corpus it is found in
  under 3 s.
* `.github/workflows/fuzz.yml` repeats this weekly and on demand (30 minutes
  per target by default). It is not a pull-request gate.

== Required before broad promotion

* Broader independent YAML corpus testing beyond the committed contract corpus.
* Sustained fuzzing, mutation campaigns and complete current taxonomy evidence.
* Live Windows, Linux and macOS CI receipts at the proposed commit.
* Published-commit CI proof receipts and the open production-refinement obligations.
* Offline Guix build with all git dependencies and the required Rust compiler.
* Wolfi/Podman execution, SBOM, signed Stapeln bundle and strict admission evidence.
* Representative estate consumer acceptance and reviewed pin updates.

These are open acceptance requirements. This document, the presence of a file,
and a green advisory workflow are not evidence that they have all passed.
