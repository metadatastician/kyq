== Scope (handover step 3)

Search `hyperpolymath/MetaManifold-WebUI` for:

* Application code: Julia (`Oxygen.jl` handlers), TypeScript frontend (`fetch`, `JSON.parse`),
  middleware.
* Configuration: `*.json`, `*.yaml`, `*.yml`, `*.toml`.
* Persistence: DB JSON columns, file IO, generated artifacts.
* Generated artifacts: build outputs, benchmarks, scripts.
* Tests, workflows (`.github/workflows/*.yml`), hooks, installers.

Method (run from the MetaManifold-WebUI repository root):

[source,shell]
----
rg -n 'JSON\.parse|JSON\.stringify|JSON3|YAML\.|oxygen.*json|serde_json|\.json\s*\(|\bfetch\s*\(|\.(text|arrayBuffer|bytes|blob)\s*\(|\b\w+\.body\b|HTTP\.payload'
rg --files -g '*.{json,yaml,yml}'
----

Manually review matching files and follow response consumers: `.json()` is an
implicit JSON parse even without `JSON.parse`. Record raw-body reads and whether
they parse JSON, carry opaque data, or read local files. Search hits alone do
not establish a JSON boundary.

Record pinned `ijson-jcs` commit and estate KYAML profile commits here.

== Classification (handover step 4)

For each file found, assign:

* *first-party* — MetaManifold owns format; must be centralised behind kyq adapters (Phase 5 step 24).
* *legacy/versioned* — old persisted format; version bump required (step 32).
* *third-party* — external API; validate inbound.
* *generated* — CI/build output; emit KYAML/JCS.
* *invalid test fixture* — intentionally broken; never rewrite (step 31).
* *independent reference oracle* — ijson-jcs vectors; never counted as violation.
